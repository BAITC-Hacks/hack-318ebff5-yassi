# NAQTY

Қазақ тіліндегі кәсіпкерлік оқу веб-қосымшасының жұмыс істейтін демо нұсқасы.

## Іске қосу

Node.js 20 немесе одан жаңа нұсқасын орнатыңыз. Осы қалтада терминалды ашып:

```sh
node server.mjs
```

Браузерде http://127.0.0.1:4173 мекенжайын ашыңыз. Тоқтату: Ctrl+C. Қосымша кітапхана орнату қажет емес.

## Қолдану

1. «Тіркелу» арқылы атыңызды, демо поштаны және кемінде 8 таңбалы уақытша демо құпиясөзді енгізіңіз.
2. Жас, тәжірибе деңгейі және бұрынғы бизнес туралы сауалнаманы толтырыңыз.
3. Тапсырманы ашып, «Бастау», «Жауапты сақтау», «Аяқтау» әрекеттерін қолданыңыз. Аяқтау үшін кемінде 20 таңбалы жауап керек.
4. Оқу орталығындағы бес курстың 11 сабағын оқып, аяқталғанын белгілеңіз.
5. Профильде деңгейіңізді өзгертіп, ұсынылатын тапсырмалардың өзгеруін тексеріңіз. Бұрынғы жетістіктер сақталады.

## Демо шектеулері

- Кіру — нақты авторизация емес. Осы браузердегі профиль демо пошта бойынша ашылады. Құпиясөз тек пішім бойынша тексеріледі, еш жерде сақталмайды және сәйкестендіру үшін қолданылмайды. Нақты құпиясөз бен құпия деректерді енгізбеңіз.
- Деректер localStorage ішінде тек осы браузерде сақталады. Басқа құрылғыға синхрондалмайды; браузер деректерін тазалау прогресті жояды.
- NAQTY AI дайын қазақша оқу жауаптарын береді; сыртқы AI API қосылмаған. API кілті жоқ. «Демо қате күйін көру» батырмасы қате мен қайта көру әрекетін көрсетеді.
- Жоба қаржысы — оқу үлгісі, нақты нәтиже немесе табыс кепілі емес.
- Нақты өнімге көшіру үшін серверлік авторизация, пайдаланушыға тиесілі деректер базасы және сервер арқылы AI интеграциясы қажет.
- Фотолар мен қаріп интернеттен жүктеледі. Фото авторлық құқықтары бастапқы иелеріне тиесілі; кең аудиторияға жариялар алдында пайдалану лицензиясын тексеріңіз.

## Файлдар

- `dist/index.html` — негізгі бет.
- `dist/style.css` — телефон мен компьютерге арналған дизайн.
- `dist/app.js` — маршруттар, деректер, сауалнама және әрекеттер.
- `server.mjs` — жергілікті іске қосу сервері.

Барлық оқыту мәтіні қазақ тілінде. Жас тапсырма ұсынуға, рейтингке немесе мүмкіндіктерге әсер етпейді.
