# AI Sana — идеядан нәтижеге

Бизнес тапсырмаларын толықтыру, дайындық рейтингін есептеу және студенттік командаларды ашық таңдау платформасының жұмыс істейтін MVP нұсқасы.

## Іске қосу

Python 3.10 немесе жаңа нұсқа қажет. Сыртқы пакеттер орнатылмайды.

```powershell
python server.py
```

Браузерде **http://localhost:8000** мекенжайын ашыңыз. Серверді тоқтату: `Ctrl+C`. Портты өзгерту үшін `PORT` орта айнымалысын орнатыңыз.

Алғашқы іске қосылғанда SQLite базасына 5 тапсырма, олардың бастапқы сипаттамалары, 5 команда және 5 ұсыныс қосылады. Өзгерістер жергілікті `sana.db` файлында сақталады. Мысалдардағы ұйымдар, контактілер мен ұсыныстар — демо деректер.

## Мүмкіндіктер

- Қазақша, мобильді экрандарға бейімделген интерфейс.
- Логин және құпиясөзбен тіркелу/кіру, шығу, жеке профиль және аватар.
- Бизнес пен студенттің жеке аккаунттары; серверде рөл мен тапсырма иесін тексеру.
- Тапсырмаларға JPG, PNG, WebP суретін жүктеу (2 МБ дейін), алдын ала қарау және алып тастау.
- Еркін сипаттамадан кемінде 3 нақтылаушы сұрақ алу (демо көмекші 6 сұрақ береді).
- Карточканы өңдеу, растау, жарияламай сақтау немесе каталогқа жариялау.
- 0–100 рейтингі, әр көрсеткіштің ұпайы, жетіспейтін ақпарат және өңдеуден кейін қайта есептеу.
- Тақырып, дайындық деңгейі, кілт сөз бойынша сүзгі; рейтинг және жаңалығы бойынша сұрыптау.
- Командалардың шектеусіз ұсыныстары: идея, жоспар, мерзім, прототип сілтемесі.
- Бизнестің бір немесе бірнеше команданы қолмен таңдауы, ұсынысты қабылдамауы.
- Таңдалған команданың кезеңін қолмен растау және бір рет 25 ұпай беру.

## Архитектура

`server.py` — Python HTTP сервері, JSON API, серверлік валидация, рейтинг және SQLite. `static/index.html`, `static/style.css`, `static/app.js` — тәуелділігі жоқ браузер интерфейсі. SQLite кестелері: `tasks`, `teams`, `proposals`, `users`, `sessions`. API мен статикалық файлдар бір серверден беріледі. Сервер тек `127.0.0.1` адресін тыңдайды.

Негізгі API: `GET /api/state`, `POST /api/assist`, `/api/tasks`, `/api/proposals`, `/api/decision`, `/api/milestone`.

Аккаунт түрі тіркелу кезінде таңдалады. Құпиясөздер PBKDF2-SHA256 (600 000 итерация, жеке salt) арқылы хештеледі. Сессия 7 күнге HttpOnly / SameSite=Lax cookie арқылы сақталады; базада токеннің хеші ғана болады. Шығу сессияны жояды. Кіру әрекеттері шектеледі.

Бизнес тек өз тапсырмаларын және оларға түскен ұсыныстарды басқарады. Студент тіркелгенде жеке команда ашылады; ол тек сол команда атынан ұсыныс жібереді. Жарияланбаған тапсырмалар тек иесіне көрінеді. Бастапқы демо тапсырмалар өзгертілмейді; тексеру үшін өз тапсырмаңызды жасаңыз.

Суреттер тек PNG/JPEG/WebP ретінде 2 МБ шектеуімен тексеріліп, SQLite ішінде сақталады. Суретсіз карточкаларға жергілікті SVG иллюстрациялар көрсетіледі. Бұл жергілікті MVP: email растау, құпиясөзді қалпына келтіру және Instagram арқылы OAuth кіруі қосылмаған. Интернетке жариялау алдында HTTPS және Secure cookie орнатылуы тиіс.

## Рейтинг және каталог ережелері

Рейтинг = расталған, бос емес өрістердің салмақтарының қосындысы. Мәтіннің мағыналық сапасы автоматты түрде бағаланбайды.

| Өріс | Ұпай |
|---|---:|
| Мәнмәтін және қажеттілік | 20 |
| Деректер мен материалдар | 20 |
| Күтілетін нәтиже | 15 |
| Табыс критерийлері | 15 |
| Шектеулер | 10 |
| Пайдаланушылар | 10 |
| Бизнеспен байланыс | 10 |

0–39: алғашқы нұсқа; 40–69: жұмысқа жарамды; 70–89: дайын; 90–100: басымдық берілген. Расталмаған карточка 0 ұпай алады және жарияланбайды. Әр өңдеуде пайдаланушы қайта растауы керек.

Жарияланған тапсырмалар рейтингке қарамастан бәріне көрінеді; төмен рейтинг ұсыныс жіберуге кедергі емес. Әдепкіде рейтинг бойынша кему ретімен орналасады. «Ұсынылған» бөлімі 40+ ұпайлы тапсырмаларды көрсетеді: бұл дайындыққа негізделген қарапайым сүзгі, жекелендірілген AI ұсынымы емес. Таңдау тек бизнес әрекеті арқылы жасалады.

## AI демо режимі

Сыртқы модель қосылмаған. Хакатон шартындағы жергілікті алмастырғыш қолданылды: `/api/assist` бастапқы сипаттаманы өзгертпей `context` өрісіне көшіреді, қалған алты өріске нақтылаушы сұрақ ұсынады. Ол жаңа фактілер қоспайды; жауаптарды пайдаланушы толтырады. Интерфейс бұл режимді ашық белгілейді.

Промпт `server.py` ішіндегі `PROMPT` тұрақтысында және API жауабында бар. Кіріс: `{"description":"Клиенттердің сұрақтарына көп уақыт жұмсаймыз"}`. Шығыс: `{"mode":"local-demo","context":"...","questions":[{"field":"data","label":"...","question":"..."}],"prompt":"..."}`.

Бос/қысқа кіріс серверде қабылданбайды. Интерфейс жауаптың құрылымын, сұрақтар санын тексереді, HTTP/JSON қатесін көрсетеді және қайта жіберуге мүмкіндік береді. Нақты LLM интеграциясында API кілтін тек серверде сақтап, осы жауап келісімшартын сақтау қажет.

## Тексеру

```powershell
python -m unittest discover -s tests -v
```

Тесттер рейтинг шекараларын, растауды, жариялау валидациясын, төмен рейтингке ұсыныс жіберуді, қолмен таңдауды, кезең ұпайының қайталанбауын және SQLite сақталуын тексереді. Тесттер уақытша база қолданады.

## 5 минуттық демонстрация

1. «Тіркелу» арқылы бизнес аккаунтын ашыңыз. Профильге сурет қосыңыз. Содан кейін «Тапсырма қосу»: атау, ұйым және қысқа мәселе сипаттамасын енгізіңіз.
2. Сұрақтарды алыңыз. Бірнеше өрісті толтырып, алдын ала рейтингтің өсуін көрсетіңіз.
3. Мәліметтерді растап, тапсырманы жариялаңыз. Каталогтағы орны мен ұпай түсіндірмесін ашыңыз.
4. Карточканы толықтырып, қайта растаңыз; рейтинг пен каталогтағы орын өзгереді.
5. Аккаунттан шығып, студент аккаунтын тіркеңіз; осы тапсырмаға идея, жоспар, мерзім және сілтеме жіберіңіз.
6. Бизнес аккаунтына қайта кіріп, ұсынысты қабылдаңыз немесе қабылдамаңыз. Қабылданған ұсыныстың кезеңін растаңыз; «Командалар» бетінде +25 ұпайды көрсетіңіз.
7. Бетті жаңартып, деректердің сақталғанын тексеріңіз.

## Жаңартудан кейін

Бұрынғы серверді терминалда `Ctrl+C` арқылы тоқтатып, `python server.py` командасымен қайта қосыңыз. Браузерде `Ctrl+F5` басыңыз. Бұрынғы деректер сақталады, аккаунт кестелері автоматты түрде қосылады.
