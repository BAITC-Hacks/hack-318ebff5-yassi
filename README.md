# Sana Quest

Бизнес өкілдері мен студенттік командаларды байланыстыратын қазақша MVP.

## Іске қосу

Python 3.10 немесе жаңа нұсқа қажет. Қосымша пакеттер орнатылмайды.

```powershell
python server.py
```

Браузерде **http://localhost:8000** ашыңыз. Тоқтату: `Ctrl+C`. Жаңартудан кейін серверді қайта қосып, `Ctrl+F5` басыңыз. VS Code конфигурациясы 8000 портын ашады; серверді бөлек қосу керек. Басқа порт үшін `PORT` орта айнымалысын орнатыңыз.

Деректер `sana.db` SQLite файлында сақталады. Жаңа кестелер мен өрістер бұрынғы деректерді жоймай автоматты қосылады.

## Мүмкіндіктер

- Ашық таныстыру беті, каталог, тапсырманың жеке беті.
- Электрондық пошта, құпиясөзді қайталау және рөл арқылы тіркелу; кіру және шығу.
- Жаңа пайдаланушы кабинетке өтпей тұрып профилін толтырады.
- Бизнес профилі: жеке мәліметтер, компания, логотип, байланыс және кеңес беру тәртібі.
- Студент профилі: оқу орны, мамандық, курс, дағдылар, технологиялар, қызығушылықтар, команда мен оның мүшелері.
- Аватар мен тапсырма суреттері: JPEG/PNG/WebP, әрқайсысы 2 МБ дейін.
- Еркін сипаттама, 7 нақтылаушы сұрақ, өңделетін карточка, растау және жариялау.
- Каталогта іздеу, тақырып/дайындық бойынша сүзгілер, рейтинг/жаңалық бойынша сұрыптау.
- Командалардың ұсыныстары, қолмен таңдау/қабылдамау, прототип ұсыну, кезеңді растау және +10 ұпай.

## Демо режим

Басты бетте және кіру терезесінде **«Демо: бизнес ретінде кіру»**, **«Демо: студент ретінде кіру»** батырмалары бар. Ортақ демо аккаунттар интерфейсте белгіленеді. Оларға жеке немесе құпия мәлімет енгізбеңіз. Өзгерістер осы компьютердің базасында сақталады.

Алғашқы іске қосылғанда 5 бастапқы сипаттама, әртүрлі рейтингі бар 5 тапсырма, 5 команда және 5 ұсыныс жасалады. Ұйымдар мен командалар — белгіленген синтетикалық мысалдар, серіктестер тізімі емес. Статистика база деректерінен есептеледі.

Демо бизнес бастапқы тапсырмаларды басқарады; демо студент бірінші демо команда атынан әрекет етеді. Нақты аккаунттар бөлек сақталады; демо кіру оларға құқық бермейді. Бұл режим жергілікті көрсетуге арналған.

## Рейтинг пен каталог ережелері

Рейтинг тек бизнес растаған бос емес тапсырма өрістерінен есептеледі. Мәнмәтін және қажеттілік — бөлек өрістер, екеуі де толғанда 20 ұпай беріледі.

| Көрсеткіш | Ұпай |
|---|---:|
| Мәнмәтін және қажеттілік | 20 |
| Деректер мен материалдар | 20 |
| Күтілетін нәтиже | 15 |
| Табыс критерийлері | 15 |
| Шектеулер | 10 |
| Пайдаланушылар | 10 |
| Бизнеспен байланыс | 10 |

0–39: **Бастапқы жоба**; 40–69: **Жұмысқа жарамды**; 70–89: **Дайын**; 90–100: **Басымдықты**. Расталмаған карточка 0 ұпай алады. Өңдеуден кейін қайта растау қажет. Тапсырманың жеке бетінде прогресс, әр көрсеткіш, жетіспейтін мәлімет, келесі әрекет пен одан алынатын ұпай көрсетіледі.

Компания танымалдығы, профильдің толықтығы, студенттің деректері мен команда ұпайлары рейтингке әсер етпейді. Қазіргі MVP ақпараттың бар болуын тексереді; мәтіннің мағыналық сапасын бағаламайды.

Барлық жарияланған тапсырма көрінеді. Төмен рейтинг ұсыныс жіберуге кедергі емес. Жарияланбаған жоба тек иесіне көрінеді. Әдепкі сұрыптау — рейтингтің кему реті. «Ұсынылған» бөлімі — 40+ дайындық ұпайлы тапсырмалар; жекелендірілген AI ұсынымы емес.

## Ұсыныстар және жұмыс кезеңі

Идея, жоспар, мерзім міндетті; бастапқы ұсыныста прототип сілтемесі міндетті емес. Ұсыныстар саны шектелмейді. Ұсыныс мазмұны тиісті бизнеске және жіберген командаға ғана көрінеді. Каталогта жалпы ұсыныс саны көрсетіледі.

Бизнес бір, бірнеше немесе ешбір команданы таңдай алады. AI орындаушыны тағайындамайды.

Таңдалған студент «Менің жобаларым» бетінде прототип сілтемесін жібереді. Содан кейін бизнес «Кезеңді растау» батырмасын баса алады. Командаға **10 ұпай** беріледі. Қайта растау қосымша ұпай қоспайды; ұпай сақталған `milestone` белгісінен есептеледі.

## Авторизация және құпиялық

Жергілікті нақты авторизация бар: PBKDF2-SHA256, 600 000 итерация, жеке salt. Базада сессия токенінің хеші сақталады; браузерде HttpOnly / SameSite=Lax cookie қолданылады. Сессия 7 күн жарамды; шығу оны жояды. Құпиясөздер localStorage-ға жазылмайды. Кіру әрекеттері жиілік бойынша шектеледі.

Сервер рөлді, тапсырма иесін және команда иесін тексереді. Толтырылмаған профильмен тапсырма/ұсыныс жасауға болмайды. Байланыс ақпараты каталогқа автоматты көшірілмейді. Тапсырманың байланыс өрісінде пайдаланушы өзі жариялаған ақпарат қана болады.

Шектеулер: email растау, құпиясөзді қалпына келтіру, Instagram OAuth және өндірістік орналастыру жоқ. Сервер тек `127.0.0.1` адресін тыңдайды. Интернетке шығару алдында HTTPS, Secure cookie және ортақ демо аккаунттарын ажырату керек.

## AI көмекші

Сыртқы модель қосылмаған. **Жергілікті демо көмекші** сипаттаманы өзгертпей сақтап, толықтыруға арналған 7 сұрақ ұсынады. Жауаптарды пайдаланушы толтырады; ойдан фактілер қосылмайды. Промпт `server.py` ішіндегі `PROMPT` тұрақтысында және API жауабында бар.

Кіріс: `{"description":"Клиенттердің сұрақтарына көп уақыт жұмсаймыз"}`.

Шығыс: `{"mode":"local-demo","context":"...","questions":[{"field":"need","label":"...","question":"..."}],"prompt":"..."}`.

Кіріс тексеріледі. Клиент HTTP/JSON қатесін, қате жауап құрылымын және сұрақ саны жеткіліксіздігін өңдейді. Браузер кодында құпия API кілті жоқ.

## Жоба құрылымы

- `server.py`: HTTP/JSON API, рейтинг, SQLite, рұқсаттар, демо деректер, кезеңдер.
- `accounts.py`: тіркелу, кіру, хештер, сессиялар, суреттерді тексеру.
- `profiles.py`: профиль схемалары, валидация және демо профильдер.
- `static/app.js`: каталог, тапсырма редакторы, ұсыныстар, рейтинг.
- `static/account.js`: басты бет, авторизация, профиль, кабинеттер, суреттер.
- `static/style.css`, `account.css`, `quest.css`: бейімделетін интерфейс.
- `static/images/`: жергілікті SVG иллюстрациялар.
- `tests/test_platform.py`: рейтинг, аккаунт, рұқсат, профиль және толық сценарий тесттері.

Барлық бет бір дерек көзін — `GET /api/state` пайдаланады. POST маршруттар: `/api/register`, `/api/login`, `/api/logout`, `/api/demo`, `/api/profile`, `/api/assist`, `/api/tasks`, `/api/proposals`, `/api/decision`, `/api/submit-prototype`, `/api/milestone`.

## Тексеру

```powershell
python -m unittest discover -s tests -v
```

Тесттер жеке уақытша SQLite файлын пайдаланады; негізгі базаға тимейді.

Демонстрация:

1. Демо бизнес ретінде кіріп, профильді өңдеп сақтаңыз.
2. Толық емес сипаттамадан тапсырма құрып, нақтылаушы сұрақтарға жауап беріңіз.
3. Карточканы толықтырып, рейтинг өсуін көріңіз; растаңыз және жариялаңыз.
4. Шығып, демо студент ретінде кіріңіз.
5. Каталогтан тапсырманы тауып, ұсыныс жіберіңіз.
6. Демо бизнеске кіріп, команданы таңдаңыз.
7. Студент кабинетінде «Таңдалды» мәртебесін көріп, «Менің жобаларым» бөлімінен прототип сілтемесін жіберіңіз.
8. Бизнес кезеңді растайды; командаға 10 ұпай беріледі. Қайта растауда ұпай өспейді.
9. Бетті жаңартып, деректердің сақталғанын тексеріңіз.
